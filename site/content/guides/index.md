description: Task guides for Marey. Install and check scenes, export every format, embed the player, check scenes in CI, edit an export in a Lottie editor, and read the compiler's errors.
---

The guides cover tasks rather than the language: getting a scene out of the
browser and into a file, a web page or a repository's checks. The language
itself is taught in [the course](/learn/), and stated in full in
[the reference](/reference/).

- [Install and check](/guides/install/): install `marey-lang`, check scene
  files with `marey check`, its options and exit codes, and the compiler as a
  JavaScript function.
- [Export](/guides/export/): every format `marey export` writes, its options,
  what the frames hash proves, and the playground's Export menu.
- [Embed a scene](/guides/embed/): the `<marey-player>` element, its
  attributes, events, error codes and JavaScript API, styling, sizing and
  the WebGL context budget.
- [Check scenes in CI](/guides/ci/): a plain workflow step,
  and the Marey GitHub Action, its inputs and outputs, annotations, artifacts
  and pinning.
- [Edit an export in a Lottie editor](/guides/lottie/): what a Marey Lottie
  file holds, its fitted keyframes, what is baked into it, and how to retime a
  motion.
- [Reading errors](/guides/errors/): how the compiler's messages read, and
  twelve common mistakes with their fixes.

[Lesson 14](/learn/ship-it/) is a shorter tour of the first four, with one
example of each.
