Marey is a small language for 2D motion. A scene is a block of text that names shapes, how they move and for how long. The same text always produces the same frames, so a scene can be diffed, reviewed and exported like source code.

The course is a sequence of short lessons. Each lesson introduces a few words of the language, shows them running next to their source, and ends with a scene built only from what the course has covered so far.

## Where to start

Open the [playground](/) to write a scene straight away, or read the [guides](/guides/) for installing the command line tool and the embeddable player. The [reference](/reference/) lists every keyword and property.
